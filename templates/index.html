📈 Elbow & Silhouette Analysis

The Elbow chart shows inertia (sum of squared distances to cluster centres). Pick k where the curve "bends". The Silhouette score (higher = better) measures how well each point fits its own cluster vs others.

🔵 2D Cluster Scatter (PCA)

PCA compresses 4 features into 2 dimensions so we can draw the clusters on a flat plane. Each colour = one segment. Perfect clusters = tight, non-overlapping blobs.

📦 Feature Distributions per Segment

Box plots show the spread of Age, Income, and Spending Score inside each segment. The middle line = median. The box = middle 50% of values. Dots outside = outliers.

🌡️ Segment Heatmap

Average feature values per segment – green is high, red is low. Great for quickly spotting which segments are "high income + high spend" vs "low income + low spend".

👥 Segment Profiles & Recommendations

Each segment gets a short business recommendation based on its average age, income, and spending score.
